## 📖 Overview

**CourseCompass** is an AI-powered personalized learning platform tailored for college students. It solves academic cognitive overload by transforming unstructured lecture slides, textbook PDFs, lecture videos, and notes into structured prerequisite knowledge maps, grounded AI tutoring sessions, and adaptive diagnostic quizzes.

Every answer generated by CourseCompass is visibly backed by verifiable citations directly from student-uploaded material with page numbers, slide indexes, and video timestamps.

---

## ✨ Core Features

- **Multimodal Course Ingestion**: Upload textbook PDFs, lecture slides, notes, images, audio, and video lectures. Documents are parsed into clean text, diagram extracts, and semantic chunks.
- **Source-Grounded AI Tutor**:
  - *Supported by your course*: Directly backed with page and excerpt proof.
  - *Partially supported*: Identifies parts found in course materials and parts requiring external clarification.
  - *Not found in your course*: Explicitly flags out-of-syllabus topics.
  - *Interactive Citation Inspector*: Click any citation badge to view source excerpts, page numbers, and exact evidentiary context.
- **Prerequisite Knowledge Graphs & Concept Maps**: Interactive DAG visualization illustrating relationships between concepts (foundations, prerequisites, and advanced topics).
- **Adaptive Quizzes & Misconception Diagnostics**: Tailors questions based on weak concepts, tracks confidence scores, and classifies misconceptions with diagnostic study advice.
- **Personalized Study Plans & Sprints**: Time-bounded study schedules prioritizing prerequisite gaps, low-mastery concepts, and impending exam dates.
- **Enterprise Multi-Tenant Security**: Strict user-level data isolation (`userId`, `courseId`), session security, rate limiting, and tamper-resistant signed resource access.

## 🚀 Getting Started Locally

### 1. Prerequisites
- **Node.js** (v18+ or v20+)
- **Python** (v3.11 or v3.12)

### 2. Backend Setup
```bash
# Navigate to backend directory
cd backend

# Install Python dependencies
pip install -r requirements.txt

# Start the FastAPI server (Port 8000)
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
API Documentation will be live at: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)  
Health Check: [http://127.0.0.1:8000/api/health](http://127.0.0.1:8000/api/health)

### 3. Frontend Setup
```bash
# In the repository root directory
npm install

# Start Vite development server (Port 3000)
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
